# Lopez Lending Group Website

Production-ready Astro marketing site for Lopez Lending Group, serving North Carolina and South Carolina.

## Run locally

- `npm install`
- `npm run dev`
- `npm run build`

## Content editing

- Site copy/data: `src/data/`
- Blog posts: `src/content/blog/`

## Placeholder values to replace

- NMLS ID (`NMLS #PLACEHOLDER`)
- Calendly URL (`CALENDLY-USERNAME-PLACEHOLDER`)
- Application URL (`APPLICATION-URL-PLACEHOLDER`)
- Social profile links and direct contact details
- Replace placeholder JPG/SVG assets in `public/images/`
